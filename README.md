# Saif Buvet

Android app for a small shop: products, sales, profit or loss, homemade items, credit sales, shop and personal expenses.

The whole app is one page, `app/src/main/assets/index.html`, shown in a WebView. It works offline and keeps its data on the phone.

Every push to `main` builds the APK with GitHub Actions and publishes it on the Releases page as `saif-buvet.apk`.
